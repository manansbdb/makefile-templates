# Makefile Templates / Templates de Makefile

## Overview / Visão geral

**EN:** Common Makefile targets for build, test, lint, and run.

**PT:** Targets comuns de Makefile para build, test, lint e run.

## Files / Ficheiros

| File | EN | PT |
|------|----|----|
| `templates/Makefile.node` | Node.js project | Projeto Node.js |
| `templates/Makefile.python` | Python project | Projeto Python |
| `templates/Makefile.generic` | Generic helpers | Helpers genéricos |

## Usage / Uso

```bash
cp templates/Makefile.node Makefile
make help
```
