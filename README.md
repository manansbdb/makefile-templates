## Install / Instalação

### 1) Clone

```bash
git clone https://github.com/manansbdb/makefile-templates.git
cd makefile-templates
```

### Use / Usar

```bash
cp templates/Makefile.node Makefile
make help
```

### Requirements / Requisitos

- `git`
- No paid services required / Sem serviços pagos
